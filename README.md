# IronMind

IronMind is a structured Android application designed to help users move from intention to action through goals, plans, and commitments.

## Project Structure

- `Docs/` - Contains authoritative project contracts and specifications.
- `IronMind/` - Contains the Android application source code.

## Development Rules

All implementation must strictly follow the rules defined in `Docs/DEVELOPMENT_RULES.md` and the `Docs/IRONMIND_IMPLEMENTATION_ROADMAP.md`.
